- **YouTube bumper ads (6s)**: "You bought a standing desk. Are you actually standing? [logo + URL]" — brand awareness at low CPV.

**Budget note**: at 100 PLN/mo, expect ~50k-100k impressions. Goal is remarketing pixel data, not direct conversions.

### A/B Test Plan

| Test | Variable | Variants | Run time | Success metric |
|------|----------|----------|----------|---------------|
| 1 | Ad format | Carousel vs Single Image | 2 weeks | CTR |
| 2 | Hook type | Problem ("you sit too much") vs Aspiration ("become a standing desk pro") | 2 weeks | CTR + landing page time |

## KPIs and Decision Rules

### Performance Targets

| Metric | Google Search | Google Display | Facebook/IG |
|--------|-------------|---------------|-------------|
| CPC | < 2.00 PLN | < 0.50 PLN | < 1.50 PLN |
| CTR | > 3% | > 0.5% | > 1.5% |
| Conversion rate | > 2% | > 0.3% | > 1% |
| Cost per pre-order | < 50 PLN | N/A (awareness) | < 50 PLN |

### Go/No-Go Decision Rules

**Week 2 checkpoint**:
- If CPC > 3x target on any channel → pause that channel, reallocate budget
- If CTR < 50% of target → rewrite ad copy, test new creatives
- If zero conversions after 1000 clicks → review landing page, not ads

**Month 1 checkpoint**:
- If cost per pre-order < 30 PLN → increase budget by 50%
- If cost per pre-order 30-50 PLN → maintain, optimize creatives
- If cost per pre-order > 50 PLN → pause paid ads, focus on organic (Reddit/HN posts)
- If cost per pre-order > 100 PLN → kill paid ads entirely, redirect budget to influencer kits

**Month 3 checkpoint**:
- Calculate total ad spend vs pre-orders generated
- Compare organic vs paid acquisition cost
- Decide: scale paid, maintain, or go fully organic

## Setup Checklist

### Google Ads Account

1. Create Google Ads account at ads.google.com (use zentala.io email)
2. Set account currency to PLN, timezone to Warsaw
3. Add billing (credit card or bank transfer)
4. Install Google Ads tag on landing page (gtag.js snippet in `<head>`)
5. Set up conversion tracking:
   - Conversion action: "Pre-order" — triggered on thank-you page or form submission
   - Conversion action: "Pricing click" — triggered on pricing section scroll/click
   - Conversion window: 30 days
6. Create Campaign 1 (Search):
   - Budget: 6.50 PLN/day (200 PLN/month)
   - Bidding: Maximize clicks initially, switch to Target CPA after 30 conversions
   - Locations: Germany, Netherlands, Sweden, Denmark, Poland
   - Languages: English
   - Ad schedule: all day (adjust after 2 weeks of data)
7. Create Campaign 2 (Display):
   - Budget: 3.30 PLN/day (100 PLN/month)
   - Bidding: Maximize impressions (awareness goal)
   - Placements: auto (let Google optimize)
8. Set up remarketing audience (site visitors who didn't convert)
9. Link Google Analytics 4 (if using) for cross-channel attribution

### Facebook Business Manager

1. Create Business Manager at business.facebook.com
2. Create a Facebook Page for the product (if not existing)
3. Create Ad Account within Business Manager, set currency to EUR
4. Install Meta Pixel on landing page:
   - Base pixel code in `<head>`
   - Event: `ViewContent` on landing page load
   - Event: `InitiateCheckout` on pre-order button click
   - Event: `Purchase` on pre-order confirmation
5. Create Custom Audiences:
   - Website visitors (last 30 days)
   - Pricing page visitors (last 30 days)
   - Pre-order form starters who didn't complete
6. Create Lookalike Audiences (after 100+ pixel events):
   - 1% lookalike of website visitors (DE, NL, SE, DK)
   - 1% lookalike of pre-order completers
7. Create Campaign:
   - Objective: Conversions (optimize for pre-order)
   - Budget: 6.50 EUR/day (~200 PLN/month)
   - Placement: automatic (feed + stories + reels)
   - Schedule: continuous, review weekly
8. Upload carousel and single image creatives
9. Set up A/B test framework (Experiments tab)

### Conversion Tracking Setup

**Google**:
```html
<!-- Google Ads conversion tracking (place on thank-you page) -->
<script>
  gtag('event', 'conversion', {
    'send_to': 'AW-XXXXXXXXX/XXXXXXXXXXXXXXXX',
    'value': 49.0,
    'currency': 'EUR'
  });
</script>
```

**Meta Pixel**:
```html
<!-- Meta Pixel base code (place on all pages) -->
<script>
  fbq('init', 'XXXXXXXXXXXXXXXXX');
  fbq('track', 'PageView');
</script>

<!-- Pre-order button click -->
<script>
  fbq('track', 'InitiateCheckout', { value: 49.00, currency: 'EUR' });
</script>

<!-- Pre-order confirmation -->
<script>
  fbq('track', 'Purchase', { value: 49.00, currency: 'EUR' });
</script>
```

**Privacy note**: both tracking scripts must respect cookie consent. Use a consent banner (e.g., Cookiebot or custom) that loads tracking only after opt-in. This aligns with EU GDPR requirements and the project's privacy-first stance.
