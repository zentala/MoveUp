# Healthy Balance Spec Pack

This folder contains the product and implementation specification for **Healthy Balance**, a desktop tray/menu-bar app for a smart height-adjustable desk.

## Files

```txt
PRD.md
DESIGN_SYSTEM.md
ARCHITECTURE.md
TASKS.md
TEST_CASES.md
CODEX_PROMPT.md
SKILL.md
```

## Recommended Codex Flow

1. Give Codex `CODEX_PROMPT.md`.
2. Ask it to read all files.
3. Start with `TASKS.md` Milestone 0 and Milestone 1.
4. Do not let it implement hardware integration yet.
5. Require tests for domain logic before UI polish.

## Product Core

```txt
Sit. Stand. Flow.
A quiet tray app for healthier desk rhythm.
```
